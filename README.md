# Zaishen Ultimate Bravery – The Versatile Hero's Handbook

Random off-meta builds for Guild Wars 1 that still work. Solo, hero teams of 4/6/8 and 1v1 PvP, weirdness 1–10, "Today I go full bravery", English and German.

**Open the tool: https://krvtt.github.io/gw1-ultimate-bravery/** (beta)

## Using it

- **Desktop:** open the link. That's it.
- **Phone:** open the link, then *Share → Add to Home Screen* (iPhone/iPad, Safari) or *⋮ → Install app / Add to Home screen* (Android, Chrome). It then starts like an app and works offline once loaded.
- **Your data stays in your browser:** skill base, imported characters, logbook, titles and ratings are stored on your device only. Nothing is uploaded. Use *Account → Backup* to move to another device. On iPhone/iPad the Home Screen app has its own storage, separate from Safari.
- **Share a build:** use the Share button on the build page. Anyone who opens the link sees exactly the same build, whatever their own settings are – even after later updates (old links then show the saved bars). Links contain the skill pool, never character names.
- **Not sure what something means?** Tap the small **?** buttons.
- **Feedback:** [open an issue](https://github.com/krvtt/gw1-ultimate-bravery/issues/new/choose) – build feedback, bugs or ideas. What changed: [CHANGELOG](CHANGELOG.md).
- **Your own characters:** *Account → My characters* imports `character_completion.json` from [GWToolbox++](https://www.gwtoolbox.com/). Your bar then only uses skills the chosen character has learned; heroes use what all your characters know.

## Repository

| Folder | Content |
|---|---|
| `docs/` | The website served by GitHub Pages (Settings → Pages → *Deploy from a branch* → `main` / `/docs`). Generated by `src/build.py` – don't edit by hand, except `docs/icons/`. |
| `src/` | Generator, interface, knowledge base, data build and tests |
| `dev/` | Roadmap and task briefs for follow-up work (German); `CLAUDE.md` is the technical guide |
| `tools/fundorte_abrufen.py` | Fetches wiki data and icons (Python standard library, HTTPS to wiki.guildwars.com and gwpvx.fandom.com only, max. 1 request/s) |

Build and test (Python 3, Node; browser tests need Playwright with Chromium):

```
python3 src/build.py                                   # docs/ (and dist/ if present)
node src/test_addons.js && node src/test_rules.js && node src/test_team.js && node src/test_conflicts.js
python3 src/test_fundorte.py
NODE_PATH=$(npm root -g) node src/smoke_app.js         # also smoke_kb.js, smoke_ui.js, smoke_release.js, smoke_next.js
```

`src/data.js`, `src/wiki.js` and `src/kb_data.js` are generated by `src/build_data.py` from [gw-skilldata](https://github.com/build-wars/gw-skilldata) and the wiki package from `tools/fundorte_abrufen.py` (not part of the repo). They are committed, so `src/build.py` works on a fresh clone.
