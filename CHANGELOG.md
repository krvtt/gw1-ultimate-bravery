# Changelog

## Beta 2 – 2026-10-11
- **Links stay stable:** every build link now also stores the generator version and the template codes. If the generator changes later (tuning), an old link shows the bars exactly as they were saved, with a button to roll the same seed with the current version. Team links keep re-rolled heroes, too.
- **Share button** on the build page: opens the share sheet on phones, copies the link on desktop. (The installed phone app has no address bar.)
- **Help everywhere:** small **?** buttons explain weirdness, Full Bravery, engines, friction, self-sabotage, the points multiplier, template codes, heroes, skill pool, connections and the experimental modes. Tap or click, works on phones.
- **Full Bravery is now a clear 0 · 1 · 2 · 3 switch** with a one-line explanation instead of three unlabeled boxes.
- **Experimental labels** on Roll your Destiny, PvP 1v1 and the GWToolbox++ character import.
- **Feedback link** in the footer and on the About page (GitHub issue forms for bugs, ideas and build feedback).
- Card actions wrap on narrow screens; dialog fields line up.

## Beta 1 – 2026-10-02
- Web app on GitHub Pages: installable on phones, works offline after the first visit, updates itself.
- Import your characters from GWToolbox++ (`character_completion.json`); "Use my characters / Start blank" switch on the start page; pick one of your characters in the class overlay.
- Shared links reproduce the exact build regardless of the receiver's settings.
- "Your last build" on the start page, backup reminder, persistent storage request.
- Real heroes with role guardrails, Pick 1 of 3, Pick your Signature, Roll your Destiny, titles and achievements, logbook with points.
